
This is my (rather rough) implementation of the computer game pong using love2d.

I first implemented it in a non-object oriented way and then re-implemented it by creating the Ball and Paddle classes as my knowledge of the lua programming language improved from zero to hero over the few hours I wrote this in.

In the non-OO version the paddle would support friction and momentarily grip the ball for a configured length of time allowing the player to move the paddle before it is automatically released thereby improving 'aiming' the ball at a specific target. 

Lua is such fun.
